Условия использования приложения ассистента «Тая ИИ»

Последнее обновление: 14.08.2026

Настоящий документ является публичной офертой Правообладателя на заключение лицензионного договора на право использования мобильного приложения ассистента «Тая ИИ» на условиях, изложенных в тексте настоящих Условий использования.

1. Термины и определения

1.1. Правообладатель — физическое лицо Лысковец Юлия, являющееся разработчиком и владельцем Приложения, а также Оператором обработки персональных данных в соответствии с Политикой конфиденциальности.

1.2. Приложение — мобильное приложение ассистента «Тая ИИ» — программное обеспечение, предназначенное для установки и использования на мобильных устройствах (смартфонах и планшетах) и включающее сервис искусственного интеллекта, который формирует ответы на Запросы Пользователя. Приложение не предназначено для использования на иных устройствах.

1.3. Ассистент — функциональность Приложения, обеспечивающая ведение диалога и формирование Сгенерированного Контента в ответ на Запросы Пользователя.

1.4. Запрос — любая информация (в том числе текст и изображения), направленная Пользователем Ассистенту в целях получения Сгенерированного Контента.

1.5. Сгенерированный Контент — любая информация, созданная Ассистентом в ответ на Запрос Пользователя.

1.6. Пользователи — физические лица, достигшие 18-летнего возраста. Приложение предназначено только для лиц, достигших 18-летнего возраста. Несовершеннолетние лица не вправе использовать Приложение. Начиная использовать Приложение, Пользователь подтверждает, что ему исполнилось 18 лет.

1.7. Гостевой режим — использование Приложения без регистрации и авторизации, при котором учётная запись Пользователя не создаётся.

1.8. Политика конфиденциальности — Политика конфиденциальности Приложения, размещённая по адресу её публикации и определяющая порядок обработки данных Пользователей.

1.9. Условия — настоящие Условия использования приложения ассистента «Тая ИИ».

1.10. Партнёр — сторонняя организация или индивидуальный предприниматель (продавец товаров, поставщик услуг, агрегатор), у которого Пользователь может самостоятельно приобрести товар или услугу, найденные с помощью Ассистента.

1.11. Партнёрская ссылка — размещённая в Сгенерированном Контенте ссылка на сайт или приложение Партнёра, переход по которой может учитываться Партнёром для расчёта вознаграждения Правообладателя.
